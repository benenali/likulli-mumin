# لكل مؤمن | Likulli Mumin

تطبيق إسلامي عربي يهدف إلى توفير محتوى موثوق وأدوات يومية، مع دعم العمل دون اتصال قدر الإمكان.

> **الحالة الحالية:** مرحلة التأسيس والتخطيط. لم تُبنَ الميزات بعد، ولم تُشغّل اختبارات بناء أو تطبيق.

## مبادئ أساسية
- العربية وواجهة RTL من البداية.
- أولوية للعمل دون اتصال للمحتوى الثابت والبيانات المحلية.
- توثيق مصادر النصوص الدينية والتراخيص قبل اعتمادها.
- فصل المحتوى بحسب المصدر/المدرسة عند الحاجة، دون خلط غير موضح.
- عدم تخزين أسرار أو مفاتيح خاصة في المستودع.
- لا نعلن نجاح أي اختبار إلا بعد تشغيله والتحقق من نتيجته.

## التشغيل
لم يُضف إعداد التطبيق البرمجي بعد. سيُحدّث هذا القسم بعد اعتماد البنية الأساسية وإضافة أوامر التشغيل الفعلية.
