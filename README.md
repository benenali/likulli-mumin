# لكل مؤمن | Likulli Mumin

تطبيق إسلامي عربي قيد التطوير، هدفه توفير محتوى ديني موثوق وأدوات يومية مع أولوية للعمل دون اتصال.

## الحالة الفعلية
- تطبيق Next.js + TypeScript تأسيسي مع واجهة عربية RTL.
- إعدادات المظهر الفاتح/الداكن وحجم النص تُحفظ محلياً على الجهاز.
- أُضيف بيان PWA وService Worker وصفحة احتياطية عند انقطاع الإنترنت.
- GitHub Actions يفحص TypeScript وESLint والبناء الإنتاجي.
- **لم تُضف بعد بيانات القرآن أو التفسير أو الأذكار، ولم يُختبر سيناريو Offline داخل متصفح فعلي.** لا تعتبر بطاقات الصفحة الحالية ميزات دينية مكتملة.

## مبادئ أساسية
- العربية وواجهة RTL من البداية.
- أولوية للعمل دون اتصال للمحتوى الثابت والبيانات المحلية.
- توثيق مصدر كل نص ديني وترخيصه قبل إدخاله أو إعادة توزيعه.
- إبقاء النصوص القرآنية مطابقة للمصدر المعتمد دون تعديل.
- فصل المحتوى بحسب المصدر/المدرسة عند الحاجة، دون خلط غير موضح.
- عدم تخزين أسرار أو مفاتيح خاصة في المستودع.
- لا نعلن نجاح أي اختبار إلا بعد تشغيله والتحقق من نتيجته.

## التشغيل المحلي على Windows
يتطلب Node.js 22 أو إصداراً متوافقاً مع إعدادات المشروع، ثم من مجلد المستودع شغّل:

    npm install
    npm run dev

لفحص المشروع:

    npm run typecheck
    npm run lint
    npm run build

خدمة Service Worker تُسجّل في وضع الإنتاج فقط؛ اختبار Offline الحقيقي يحتاج تشغيل نسخة إنتاجية عبر HTTPS أو localhost، ثم فتح التطبيق مرة بالإنترنت قبل فصل الاتصال.
