# مصادر المحتوى الديني والتراخيص

## القرآن الكريم — المصدر المرشح
**Tanzil Quran Text (الرسم العثماني)** هو المصدر المرشح للنص العربي، لكن لم يُنزّل النص إلى المستودع بعد ولم يبدأ عرضه داخل التطبيق.

- صفحة الترخيص الرسمية: https://tanzil.net/docs/Text_License
- صفحة تنزيل النص الرسمية: https://tanzil.net/pub/download/index.php
- صفحة متابعة التحديثات: https://tanzil.net/updates/
- الترخيص المعلن: Creative Commons Attribution 3.0.
- شروط الاستخدام المنشورة تسمح بنسخ وتوزيع النص حرفياً، ولا تسمح بتغيير النص. يجب إظهار المصدر بوضوح، ووضع رابط إلى Tanzil لمتابعة التحديثات، وإرفاق إشعار حقوق النشر والترخيص مع النسخ.
- قبل إضافة البيانات: تنزيل نسخة من المصدر الرسمي بعد مراجعة شروطه، حفظ النص دون تعديل، تسجيل الإصدار وتاريخ التنزيل وبصمة SHA-256، والتحقق آلياً من أن أي معالجة أو استيراد لم يغيّر نص الآيات.

## ترجمات القرآن والتفسير والتلاوات
لا تُفترض أن تراخيصها مماثلة لترخيص النص العربي. يجب تسجيل مصدر وترخيص كل ترجمة أو تفسير أو تسجيل صوتي بشكل مستقل قبل تضمينه أو إعادة توزيعه.

## الأذكار والأدعية والزيارات والأحاديث
لم تُعتمد مصادرها بعد. يجب حفظ مرجع واضح لكل مادة، وتحديد تصنيفها ومراجعتها، وعدم خلط الروايات أو نسب نص غير متحقق منه إلى مصدر ديني.

## قاعدة قبول المحتوى
لا يدخل أي محتوى ديني إلى النسخة القابلة للنشر حتى يكون مصدره وإصداره وترخيصه معروفاً، وتنجح اختبارات المطابقة المناسبة. واجهة القسم وحدها لا تعني أن المحتوى جاهز.
