# خطة مشروع «لكل مؤمن»

## الهدف
بناء تطبيق إسلامي عربي أولاً، قابل للتثبيت كتطبيق ويب تقدمي (PWA)، ويعمل دون اتصال في المحتوى الذي يمكن تخزينه محلياً بأمان. الميزات الدينية لا تُعتبر منفذة قبل إدخال بيانات موثقة واختبارها.

## المبادئ غير القابلة للتفاوض
- توثيق مصدر كل نص ديني وحقوق استخدامه؛ لا نولّد آيات أو أحاديث أو أدعية وننسبها للمصادر.
- عرض المواد المشتركة والمواد الخاصة بكل مصدر/مدرسة في أقسام واضحة منفصلة، مع بيان المصدر والمنهج وعدم خلط الروايات.
- Offline-first للمحتوى الثابت والإعدادات والمفضلة والتقدم المحلي؛ المزامنة والخدمات الحية تتطلب اتصالاً.
- عدم وضع مفاتيح سرية في المستودع أو في كود المتصفح.
- الوصولية، دعم العربية وRTL، والعمل على الهاتف والكمبيوتر.
- لا نضيف خدمات مدفوعة أو اعتماداً ضرورياً على خدمة لا توفر خطة مجانية مناسبة دون توثيق البديل والحدود.
- لا ندّعي نجاح اختبار أو نشر إلا بعد ظهور نتيجة فعلية.

## النطاق المقترح
1. الأساس: تطبيق ويب، RTL، PWA، إعدادات الخط والمظهر، بنية بيانات ومصادر.
2. القرآن: نص موثوق، بحث، علامات مرجعية وحفظ موضع القراءة، ثم التفسير والتلاوات بعد مراجعة التراخيص.
3. الصلاة: مواقيت محسوبة بإعدادات موقع/طريقة واضحة، القبلة، وتنبيهات مع توضيح قيود المتصفح والعمل بالخلفية.
4. الأذكار والأدعية والزيارات: مصدر وإسناد/مرجع حيث يتوفر، وتصنيف واضح بحسب المصدر.
5. أدوات: مسبحة، ورد يومي، خطة ختمة، تقويم هجري ومناسبات.
6. العمل دون اتصال: حزم محتوى مختارة، حفظ محلي، وإظهار حالة الاتصال وحدود المحتوى المخزن.
7. الحساب والمزامنة اختيارياً بعد إقرار نموذج الخصوصية والأمان.
8. لوحة إدارة لاحقاً، مع صلاحيات محكومة وتدقيق للعمليات.

## ما أُنجز فعلياً حتى الآن
- هيكل Next.js وTypeScript وواجهة RTL أولية.
- إعدادات المظهر وحجم النص مع حفظ محلي.
- أساس PWA: manifest وService Worker وصفحة احتياطية Offline.
- GitHub Actions: آخر فحص للالتزام 8401695 نجح في TypeScript وESLint والبناء الإنتاجي.
- لم يُختبر Offline في متصفح فعلي، ولم يُضف المحتوى الديني بعد.

## خارج المرحلة الحالية
لا نبني قاعدة بيانات دينية واسعة، ولا نضيف تسجيل دخول أو إشعارات أذان أو مزامنة قبل حسم مصادر البيانات، التراخيص، وطريقة التحقق.

## قرارات يجب حسمها قبل المحتوى الديني
- المصادر المعتمدة للقرآن والتفسير والتلاوات والأذكار والأدعية.
- المدارس/المذاهب المطلوب عرضها وكيفية تسمية الأقسام ومراجعة المحتوى.
- طرق حساب الصلاة والموقع الافتراضي ومذهب حساب العصر.
- لغات الواجهة المطلوبة بعد العربية.
- سياسة الخصوصية والاحتفاظ بالبيانات إن أضيفت حسابات.
